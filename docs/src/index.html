    Which kernel

    This page carries OpenCascade compiled to WebAssembly, and builds the geometry itself. A native kernel does the same work with the real OCAF document behind it — labels, TFunction drivers, TNaming results — and can write .cbf, STEP and OBJ to disk.

    1. Build it once: cmake -S ocaf -B ocaf/build && cmake --build ocaf/build -j
    2. Or in Python: pip install cadquery-ocp && python -m ocafpy serve
    3. Serve a model: ocaf/build/ocafcad serve ocaf/examples/cube_fillet.ocaf.json

    Model file — .ocaf.json

    The parametric model, no geometry — every feature, its arguments and its references. Paste one in and the kernel rebuilds it.

    $ ocafcad build model.ocaf.json -o part.cbf --step part.step
