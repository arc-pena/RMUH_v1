    Connect to the kernel

    Geometry is computed by OpenCascade, not by this page. Run the kernel next to your model and point the page at it.

    1. Build it once: cmake -S ocaf -B ocaf/build && cmake --build ocaf/build -j
    2. Serve a model: ocaf/build/ocafcad serve ocaf/examples/cube_fillet.ocaf.json
    3. Connect below — or open --ui ocaf/../docs/parametric-cad.html to run it same-origin.

    Model file — .ocaf.json

    The parametric model, no geometry. This is what the kernel reads; paste one in and press Load to have the kernel rebuild it.

    $ ocafcad build model.ocaf.json -o part.cbf --step part.step
